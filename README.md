# AI Viewer

여러 AI 채팅 사이트를 한 화면에 띄워 놓고, **같은 질문을 한 번에 보내서 답변을 나란히 비교**하는 크롬 확장 프로그램입니다.

지원하는 AI: **ChatGPT · Gemini · Claude · Meta AI**

- 각 AI의 실제 웹사이트를 그대로 띄우므로, 평소 크롬에서 로그인해 둔 계정과 요금제(무료·유료)가 그대로 적용됩니다.
- API 키가 필요 없고, 별도 비용도 들지 않습니다.
- 질문이나 답변을 어디에도 저장하거나 전송하지 않습니다.

## 주요 기능

- **한 번에 질문:** 아래 입력창에 쓰면 선택한 모든 AI에 동시에 전송됩니다. "보낼 대상" 칩으로 특정 AI를 빼거나 넣을 수 있습니다.
- **개별 질문:** 각 칸 아래 입력창으로 그 AI에만 보낼 수 있습니다.
- **이미지·PDF 첨부:** 입력창 왼쪽 클립 버튼, 붙여넣기(Ctrl+V), 끌어다 놓기로 이미지나 PDF를 넣으면 질문과 함께 각 AI에 올라갑니다. 업로드가 끝나 전송 버튼이 켜지면 자동으로 보냅니다(한 번에 최대 10개). 화면 아무 곳에나 놓거나 붙여넣어도 아래 공통 입력창에 들어갑니다.
- **화면 배치:** 2열, 3열, 2×2 중에서 고를 수 있고, 칸 하나를 크게 볼 수도 있습니다(Esc로 해제).
- **칸별 설정:** AI 선택, 화면 배율(줌), 새 채팅, 별도 창에서 열기.
- **기억:** 칸 배치, AI 선택, 배율을 다음에 열 때도 그대로 유지합니다.

## 설치

크롬 웹 스토어 등록 전에는 아래처럼 직접 설치합니다.

1. 이 저장소를 내려받거나 압축을 풉니다.
2. 크롬에서 `chrome://extensions`로 이동합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `extension` 폴더를 선택합니다.
5. 툴바의 AI Viewer 아이콘(퍼즐 모양 메뉴 안에 있을 수 있음)을 누르면 새 탭에 뷰어가 열립니다.

## 사용 팁

- **로그인:** 칸 안에서는 구글·Meta·Claude 로그인 화면이 열리지 않습니다. 로그인이 안 되어 있으면 칸에 안내와 **로그인 창 열기** 버튼이 나옵니다. 로그인이 필요하면 해당 칸의 **별도 창에서 열기**(↗) 버튼을 누르세요. 로그인을 마치고 그 창을 닫으면 칸이 자동으로 새로고침됩니다. 크롬 일반 탭에서 미리 로그인해 둬도 됩니다.
- **"사람인지 확인" 화면**이 칸 안에서 안 넘어갈 때도 같은 버튼을 쓰세요.
- **쿠키 안내창:** 칸 안에서는 사이트가 쿠키 선택을 저장하지 못해 매번 물어봅니다. 한 번 "모두 거부"나 "모두 허용"을 누르면, 그다음부터는 같은 버튼을 자동으로 눌러줍니다.

## 알려진 제한

- **Claude와 Meta AI는 칸 안에서 사이드바(과거 채팅 목록)가 보이지 않습니다.** 두 사이트가 다른 페이지 안에 표시될 때 스스로 사이드바를 숨기기 때문입니다. 필요하면 별도 창에서 열기를 사용하세요.
- **첨부는 각 사이트의 붙여넣기·파일 업로드 기능을 이용합니다.** 로그인하지 않았거나 요금제에서 해당 파일을 지원하지 않으면 칸 위에 경고가 뜨고, 이때는 칸 안에서 직접 처리하세요. 이미지와 PDF 외의 파일(Word, Excel 등)은 칸 안에서 직접 첨부해야 합니다.
- **AI 사이트의 화면 구조가 바뀌면 자동 입력이 멈출 수 있습니다.** 칸 위에 "입력창을 찾지 못함"이 뜨면 `extension/sites.json`의 해당 사이트 설정을 고쳐야 합니다(아래 참고). 이 경우에도 칸 안에 직접 입력해서 계속 쓸 수 있습니다.

## 권한과 그 이유

| 권한 | 이유 |
| --- | --- |
| `declarativeNetRequest` | AI 사이트는 다른 페이지 안에 표시되는 것을 막는 설정(X-Frame-Options, CSP)을 보냅니다. 이 설정을 **AI Viewer 탭 안에서, 뷰어나 AI 사이트가 연 칸에 한해서만** 제거합니다. 뷰어 탭을 닫거나 다른 주소로 이동하면 바로 해제됩니다. 칸 안에서 로그인 화면이 열리려 할 때 안내 페이지로 바꾸는 데도 씁니다. |
| AI 사이트 접근 권한 | 위 설정 제거와, 질문을 입력창에 넣고 전송 버튼을 누르는 데 필요합니다. |
| `accounts.google.com`, `auth.meta.com` 접근 권한 | 칸 안에서 로그인 화면이 열리려 할 때 안내 페이지로 바꾸고 별도 로그인 창을 열기 위해서만 씁니다. 이 사이트들의 내용을 읽거나 바꾸지 않습니다. |
| `storage` | 칸 배치, AI 선택, 배율, 쿠키 안내창 선택을 이 컴퓨터에만 저장합니다. |
| `favicon` | 각 AI의 아이콘을 크롬의 아이콘 저장소에서 가져와 표시합니다. |

## 개인정보

- 이 확장 프로그램은 어떤 데이터도 수집하거나 외부로 보내지 않습니다.
- 질문은 사용자가 고른 AI 사이트에만, 그 사이트의 입력창을 통해 전달됩니다.
- 저장하는 정보는 위 표의 설정값뿐이며, 크롬의 확장 프로그램 저장소(이 컴퓨터)에만 남습니다.

## AI 사이트 추가·수정

`extension/sites.json`에 사이트를 추가합니다.

```json
{
  "name": "표시할 이름",
  "url": "https://example.com/",
  "input": ["입력창 CSS 선택자", "..."],
  "send": ["전송 버튼 CSS 선택자", "..."]
}
```

- `input`과 `send`는 앞에서부터 차례로 시도합니다. 전송 버튼을 못 찾으면 Enter 키를 누릅니다.
- `zoom`(선택)에 기본 배율을 적을 수 있습니다. 예: `0.9`
- 새 사이트는 `extension/manifest.json`의 `host_permissions`와 `content_scripts.matches`에도 도메인을 추가해야 합니다.
